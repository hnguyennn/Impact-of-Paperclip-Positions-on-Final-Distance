# Impact of Paperclip Positions on Final Distance | Design of Experiments, Spring 2025

## Overview
This project was completed as part of the PSTAT 122 course at University of California, Santa Barbara, taught by Professor Peter Chi. The goal of the project was to
design an experiment and apply data analysis techniques, like factorial design and linear regression. In this project, we tested if any combination of paperclips on a paper plane, 
(nose, middle, rear), affected the final displacement of the paper plane.

## Objectives
- Design an experiment involving data collection, analyzing trends, and interpreting the results
- Applied statistical analysis to real-world data
- Communicate findings effectively with references from peer reviewed articles

## Dataset
The data was collected by hand. Two sets of data were collected, the pilot study for sample size calculations, and the actual data used for interpreting the question at hand.
8 replicates were done for the pilot study, while 10 replicates were done for the actual data collectiong, bringing the total to 18 replicates.

The experiment involved testing whether the independent variables (placements of paperclip) had any effect on the dependent variable (final displacement).

## Methods
- Sample Size calculations
- Visualization of the data
- Statistical Analysis of Factorial Design using linear model
- Model Checking using ANOVA assumptions
- Permutation Test

## Results
From our experiment, we found that no combination of paperclips on the paper plane had any effect on the final displacement of the plane. The different factors of paperclip
positions don't seem to individually affect the plane's displacements significantly. We conclude that the paperclip's weight needed to be heavier in relation to the plane itself to
see any statistically significant change in displacmenent.
